# SONIQ MAX — VST 2.4 DSP DLL Verification & Demo Suite

This folder provides an isolated test environment to verify whether `SoniqMaxDSP.dll` is working properly. It does not touch or affect the main project files.

---

## 1. Quick Verification (Run the Test Harness)

Open your terminal in the project directory and run:

```bash
python demo/test_vst_dsp.py
```

### What this test does:
1. **Direct VST 2.4 Loading:** Loads `vst/bin/SoniqMaxDSP.dll` into a headless Python VST 2.4 host via `ctypes`.
2. **Protocol & Handshake:** Verifies standard VST magic header (`0x56737450`), plugin unique ID (`'SqMx'`), and checks all 5 parameter channels.
3. **Harmonic Bass Exciter Test:** Injects a 60 Hz pure sub-bass sine wave and mathematically measures whether 2nd (120 Hz) and 3rd (180 Hz) harmonics are generated by the non-linear saturation curve.
4. **Vocal Clarity & Presence Test:** Injects a 2.8 kHz speech presence frequency and measures the +6 dB peaking EQ boost.
5. **3D Stereo Spatializer Test:** Injects audio into the Left channel and measures Haas delay (~0.33ms) and interaural cross-feed appearing on the Right channel.
6. **Soft-Knee Brickwall Limiter Test:** Injects an overdriven +8 dB signal (amplitude 2.50) and verifies that output is smoothly saturated and clamped below 1.00 without digital clipping.

## 3. System Integration Check (Equalizer APO)

To check whether Equalizer APO is configured and loading the DLL in Windows:

```bash
python demo/check_equalizer_apo.py
```

### Visual Live Verification in Windows:
1. Open Equalizer APO's GUI editor:
   `"C:\Program Files\EqualizerAPO\Editor.exe"`
2. Look at the block diagram:
   - Expand `Include: SONIQ_MAX_Config.txt`
   - Look for `VST plugin: VSTPlugins\SoniqMaxDSP.dll`
3. Play any video or song in YouTube/Spotify:
   - The **blue peak meter** in the editor will bounce in real time with the audio.
   - The **green power button** next to `SoniqMaxDSP.dll` indicates the DSP plugin is actively running on system audio.
